# ml-engineering-practice

A repo of exercises and practicing machine learning with a focus on audio machine learning, audio digital signal processing for machine learning, and generative music. The materials are originally from Velario Velardo's [Sound of AI YouTube Channel](https://www.youtube.com/@ValerioVelardoTheSoundofAI/playlists) and I have reworked the examples to use pytorch and modern tooling(tqdm, pathlib). Currently working through the different series
